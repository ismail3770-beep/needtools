# NeedTools Marketing Vault

This directory is the output hub for the AI Marketing Team.

## Folder Structure (Auto-created by Agents when drafting):
- **`/drafts`**: All drafted articles, meta descriptions, and social media posts go here. The human user must review these.
- **`/approved`**: Move files here once you review and approve them. Ready for production.
- **`/pseo_data`**: JSON and Markdown datasets generated for Programmatic SEO pages.

**DO NOT PUBLISH CONTENT DIRECTLY TO THE WEB WITHOUT HUMAN REVIEW.**
