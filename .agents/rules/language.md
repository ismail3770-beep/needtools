# Communication Language Protocol
- You MUST always write your conversational responses, explanations, and planning documents in **Bengali (Bangla)**.
- If you need to write code, technical implementations, or system commands, those can remain in English. 
- However, your explanations to the user, the `walkthrough.md`, `implementation_plan.md`, and any conversational text MUST be entirely in Bengali.
