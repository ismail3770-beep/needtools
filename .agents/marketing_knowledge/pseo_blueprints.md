# Programmatic SEO (pSEO) Blueprints

This file contains the templates and formulas for generating hundreds of scalable tool pages for NeedTools.

## Strategy
Instead of writing generic posts, we scale long-tail keywords using variables. 

## Variable Sets
1. **[Tool]**: Compress PDF, Merge PDF, JPG to PNG, WebP to PNG, Split PDF, etc.
2. **[Profession/Audience]**: Lawyers, Students, Teachers, Designers, Marketers, Developers.
3. **[Device/Platform]**: Mac, Windows, iPhone, Android, Offline.

## pSEO Pattern 1: Profession-Based
**URL Route:** `/tools/[tool-slug]-for-[profession-slug]`
**Example:** `/tools/compress-pdf-for-lawyers`
**H1:** Free [Tool] for [Profession] – 100% Private & Secure
**Sub-header:** The fastest way for [Profession] to [Action] without uploading sensitive files to the cloud.

## pSEO Pattern 2: Device-Based
**URL Route:** `/tools/[tool-slug]-on-[device-slug]`
**Example:** `/tools/convert-png-to-webp-on-mac`
**H1:** How to [Tool] on [Device] – No Software Required
**Sub-header:** Easily [Action] directly in your [Device] browser. Files never leave your device.
