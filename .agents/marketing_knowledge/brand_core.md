# NeedTools Brand Core & USP

This file acts as the absolute truth for NeedTools (needtools.app) branding. Every AI agent MUST adhere to these rules.

## 1. Core Value Proposition (USP)
- **100% Client-Side Processing**: Files are processed directly in the user's browser. They NEVER leave the device.
- **Privacy-First**: No servers, no tracking of user files, absolute data safety.
- **Zero Friction**: No login, no signup, no watermarks, completely free.
- **Speed**: Lightning-fast processing because there is no upload/download wait time.

## 2. Target Audience
- **Global**: Professionals, students, developers needing quick utilities.
- **Secondary Niche (High Priority)**: Bengali-speaking users (Bangladesh, India) who need easy-to-use tools without paying premiums.

## 3. Brand Voice
- Clear, direct, and benefit-first.
- Honest and transparent (No fake urgency, no hype).
- Helpful and empowering.

## 4. Competitors & Angle
- Competitors: iLovePDF, Smallpdf, Sejda.
- Our Attack Angle: We do not fight them on general authority. We win on "Privacy", "Offline usage", "No Upload", and "Programmatic Long-Tail Keywords" (e.g., Compress PDF for specific professions/devices).
